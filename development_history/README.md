# 制作過程の記録

このフォルダには、開発の過程で作成した、各段階のコードを残しています。

| ファイル | 内容 |
|---|---|
| 1test.py | Bottleの基本形(Hello World的な、ごく簡単な動作確認) |
| 2cafe_list.py | データベースから店舗一覧を取得して表示 |
| 3kensaku.py | 検索機能(喫煙区分・モーニング・夜営業)を追加 |
| 4radiobutton.py | 喫煙区分をラジオボタンに変更、JavaScriptでクリック時の選択解除を実装 |
| 5photo.py | 店舗写真の表示機能を追加 |
| 6cssstyle.py | CSSによるデザイン調整(1回目) |
| 7star.py | 星評価を数字表示から「★★★☆☆」形式の表示に変更 |
| 8click.py | 店舗名をクリックすると詳細ページに遷移する機能を追加 |
| 9cssstyle.py | CSSによるデザイン調整(詳細ページなど、2回目) |
| 10delete.py | 店舗情報の削除機能を追加 |

最新版(編集機能を含む完成版)は、ルートディレクトリの `app.py` です。
