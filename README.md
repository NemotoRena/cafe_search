# 喫茶店検索サイト
喫茶店情報を検索・管理できるWebアプリケーション

## 使用技術
・Python  
・Bottle (Webフレームワーク)  
・SQLite  
・HTML/CSS/JavaScript  

## 開発環境
・エディタ:Visual Studio Code  
・OS:Windows(開発時)、Ubuntu(検証時)  
・Python のバージョン:3.12  
・リモート接続:VS Code Remote - SSH(Ubuntu環境での検証時)  

## 主な機能
・喫煙区分(禁煙のみ/禁煙+分煙/全席喫煙可)、モーニング有無、夜営業有無での絞り込み検索  
・店舗ごとの詳細ページ(写真・星評価・営業時間・定休日・メモなど)  
・店舗情報の編集機能(プルダウンで喫煙区分などを選択して更新)  
・店舗情報の削除機能  
・検索条件を選択した状態のまま結果ページに反映(JavaScriptでラジオボタンの選択解除も実装)

## データベース設計
店舗データは、Excelで入力・管理し、CSV形式(cafe_list.csv)としてエクスポートしています。  
create_db.pyを実行すると、このcafe_list.csvを読み込み、SQLiteのデータベース(cafe.db)に、店名・住所・星評価・喫煙区分・営業時間・モーニング有無・夜営業有無・定休日・写真ファイル名・メモを登録します。

## 実行方法
#1.仮想環境の作成  
python -m venv venv  

#2.仮想環境の有効化  
#Windowsの場合  
venv\Scripts\activate  
#Mac/Linuxの場合  
source venv/bin/activate  

#3.必要なライブラリをインストールする  
pip install bottle  

#4.データベースを作成する  
python create_db.py  

#5.サーバーを起動する  
python app.py  

起動後、ブラウザで http://localhost:8080 を開くとサイトが表示されます。  

## 工夫した点
・SQLインジェクション対策として、SQL文にプレースホルダ(?)を使用し、値を安全に渡すようにしました  
・検索条件(ラジオボタン・チェックボックス)を、検索後もページ上で選択されたままの状態で表示されるようにしました  
・ラジオボタンはJavaScriptを使用しクリックで選択解除できる仕組みを実装しました  
・編集画面では、喫煙区分・モーニング有無・夜営業有無を自由入力ではなくプルダウン形式にし、検索条件との表記ゆれや誤入力を防ぐようにしました
