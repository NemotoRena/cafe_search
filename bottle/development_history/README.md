## 制作過程の記録

このフォルダには、開発の過程で作成した各段階のコードを残しています。

| ファイル | 内容 |
|---|---|
| 1test.py | 真っ白な背景に見出しのみ表示 |
| 2cafe_list.py | データベースから店舗一覧を取得して表示 |
| 3checkbox.py | 検索機能(喫煙区分・モーニング・夜営業)を追加 |
| 4photo.py | 写真の表示機能を追加 |
| 5cssstyle.py | CSSによるデザイン調整(トップページ) |
| 6star.py | 星評価を数字表示から「★★★☆☆」形式の表示に変更 |
| 7click.py | 店舗名をクリックすると詳細ページに遷移する機能を追加 |
| 8cssstyle.py | CSSによるデザイン調整(詳細ページ) |
| 9delete.py | 店舗情報の削除機能を追加 |

最新版(編集機能を含む完成版)は、ルートディレクトリの `app.py` です。
